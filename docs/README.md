# docs: project memory

These files live only on this PC. They are not committed to git.

Read in this order if you are new:


1. `memory.md`

   Facts, rules, decisions, session log. Update when a decision is made, and at the end of each session.


2. `checklist.md`

   The one list we work from. Tick a line when it works end to end.


3. `track.md`

   Where we are in short, the plan, and how we build each feature.


4. `backlog.md`

   Blockers, decisions, guesses to review (assumptions), inputs from KJS, later items.


5. `kb.md`

   Knowledge base. Every word and tool used in the project. Search with Ctrl + F.


6. `goal.md`

   What "done" means for Stage 1.


7. `prompt.md`

   Project rules and ready-made prompts for the AI assistant.


8. `trackEXP.md`

   Simple plan and progress for the KJS team.


9. `learning/learning-log.md`

   What we learned each day, in our own words.


10. `research/source/master-build-prompt.pdf`

   The master plan. Never edit.
