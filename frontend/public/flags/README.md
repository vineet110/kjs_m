Country flags (4:3 SVG) copied from flag-icons 7.2.3 (https://github.com/lipis/flag-icons), MIT licence
(LICENSE.txt). One file per ISO code, lowercase (`in.svg`). Used by the phone code and country pickers
(`frontend/src/components/public/CountryPicker.tsx`). Not a package: no dependency to install.
Missing: ac (Ascension Island) and ta (Tristan da Cunha); the pickers show the letter code for them.
